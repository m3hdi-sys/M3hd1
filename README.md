### 📂 Dossiers d'Architecture (Cliquer pour déployer)

<details>
<summary><b>🛡️ 01. Déploiement Mini-SOC (Wazuh, Sysmon, API VirusTotal & SOAR)</b></summary>
<br>
<ul>
  <li><b>Detection Engineering :</b> Création de règles XML sur-mesure face aux simulations d'attaques (<i>Atomic Red Team / MITRE ATT&CK</i>).</li>
  <li><b>Défense Active (SOAR) :</b> Bannissement dynamique d'IP via <code>iptables</code> lors de tentatives de brute-force SSH/RDP.</li>
  <li><b>Alerting & CTI :</b> Intégration de l'API <b>VirusTotal</b> sur le File Integrity Monitoring et script Python notifiant les alertes sur Webhook Discord.</li>
</ul>
</details>

<details>
<summary><b>🐳 02. Cluster Proxmox VE (5 Conteneurs LXC) & Automatisation ChatOps</b></summary>
<br>
<ul>
  <li><b>Micro-Architecture LXC :</b> Isolation de 5 conteneurs Debian (CT 107 à 111) administrés via <code>pct</code>, IP statiques et tunneling TCP/UDP Playit.gg.</li>
  <li><b>Panneau de contrôle Discord (Python) :</b> Commandes Slash et boutons exécutant des ordres SSH asynchrones par clés asymétriques.</li>
  <li><b>MCO & Sauvegardes :</b> Démons <code>systemd</code>, parsing de logs <code>journalctl</code> par Regex, extinction sur inactivité et backups <code>.tar.gz</code>.</li>
</ul>
</details>

<details>
<summary><b>🌐 03. Ingénierie Réseau Cisco : VPN Site-to-Site IPsec & Haute Disponibilité HSRP</b></summary>
<br>
<ul>
  <li><b>VPN IPsec (Cisco 1941) :</b> Licence <code>securityk9</code>, chiffrement AES, authentification IKE par clés pré-partagées (PSK) et vérification de l'encapsulation ESP.</li>
  <li><b>Haute Disponibilité (HSRP) :</b> Tolérance aux pannes (<i>Failover / Disaster Recovery</i>) via passerelles virtuelles et script Python mesurant le temps de bascule (SLA).</li>
</ul>
</details>
